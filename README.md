 ## MAIN ACHIEVE ##

This application is the goal to copy a folders project to developer in differente programming languages to fix something or developer a new feature.

HOW CAN I USE IT?

This application is very simple:
* Open the application (.exe) in folder *bin/Release/net7.0-windows7.0/* 
* The appearence of application is like this:

![image](https://github.com/user-attachments/assets/c52c492a-f1d0-4b95-bb29-1f2036d03797)


* Give folder *To copy* (directory which to wanna copy) and folder *To Transfer* (directory which to wanna copy) clicking in ![image](https://github.com/user-attachments/assets/d0d8c1f4-2a11-49a8-9002-0d64059362c4)
 button
* Click on **"Inicia a cópia"** and follow the process. If you want stop copy, click on **"Stop a cópia"**.
* Go to directory paste folder, open projetct and start to developer 😊
